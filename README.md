# AI Game Player

> AI 驱动的游戏自动互动系统

## 简介

利用 AI 模型（视觉理解 + 决策推理）实现游戏自动游玩与互动。通过截取游戏画面 -> AI 分析当前状态 -> 生成操作指令 -> 执行操作的闭环，实现自动化游戏体验。

## 核心特性

- 🖥️ **画面捕获** - 实时截取游戏画面
- 🧠 **AI 决策** - 基于多模态大模型理解画面并决策下一步操作
- 🎮 **操作执行** - 模拟键鼠/触屏操作，实现游戏内互动
- 📊 **行为日志** - 记录 AI 的决策过程和操作历史，便于复盘

## 项目状态

🚧 早期阶段 - 规划与原型验证中

## 技术栈

- Python（主语言）
- OpenCV / Pillow（画面捕获与处理）
- 多模态大模型 API（视觉理解 + 决策）
- PyAutoGUI / 类似库（操作模拟）
